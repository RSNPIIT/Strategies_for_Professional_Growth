# Strategies for Professional Growth (SPG) — Team 114

A structured repository containing deliverables, automated generation scripts, reports, presentations, and visual assets for the **Strategies for Professional Growth (SPG)** course project (IIT Madras BS Program — Sep 2026 Term).

---

## 📁 Repository Structure

```text
Strategies_for_Professional_Growth/
├── documents_files/       # Team contracts, self-assessments, and governance dossiers
├── pictorial_files/       # Custom illustrations, avatars, watermarks, diagrams, and UI icons
├── presentation_Files/    # Slide decks (.pptx) for group deliverables and project reviews
├── python_Files/          # Automation scripts for generating PDFs, PPTX decks, diagrams, and assets
├── report_files/          # Individual and consolidated interim reports (.pdf & .md)
├── rendered_deck/         # Rendered slide previews and visual verification outputs
├── .gitignore             # Excludes virtual environments, cache, and OS-specific metadata
└── README.md              # Project overview and repository documentation
```

---

## 🛠️ Key Components

* **Automated Document & Deck Generation (`python_Files/`):** Python scripts built to programmatically generate formatted PDF reports, PowerPoint presentations, Causal Loop Diagrams (CLDs), Gantt charts, and custom transparent stickers/watermarks.
* **Project Deliverables (`documents_files/` & `report_files/`):** Includes the Team Contract (`TC`), Group Project deliverables (`GP1`, `GP2`), Self-Assessments (`SA`), and Interim Reports (`IR`) for Team 114.
* **Visual & Diagram Assets (`pictorial_files/`):** Contains methodology pipelines, influence models, governance dashboards, team member portraits/avatars, and branding assets.

---

## 🚀 Setup & Usage

1. **Clone the repository:**
   ```bash
   git clone git@github.com:RSNPIIT/Strategies_for_Professional_Growth.git
   cd Strategies_for_Professional_Growth
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Run generation scripts:**
   Navigate to `python_Files/` or run scripts from the root directory depending on asset path configurations.
